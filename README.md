# صفحه بروزرسانی سایت

یک صفحه ساده «در حال بروزرسانی» با آیکون تنظیمات (چرخ‌دنده) و متن تایپ‌رایتر.

## فایل‌ها

- `index.html` صفحه اصلی (HTML، CSS و JavaScript در یک فایل)
- `server.js` سرور ساده Node.js بدون نیاز به نصب پکیج
- `README.md` همین راهنما

## اجرا

نیاز به Node.js نسخه 14 یا بالاتر.

```bash
node server.js
```

بعد آدرس `http://localhost:3000` را باز کن. برای تغییر پورت:

```bash
PORT=8080 node server.js
```

## بدون سرور

اگر فقط می‌خواهی روی هاست معمولی بگذاری، فایل `index.html` را آپلود کن. به `server.js` نیازی نیست.

## شخصی‌سازی

- متن: در `index.html` عبارت «در حال بروزرسانی» را هم در تگ `#typed` و هم در متغیر `text` داخل اسکریپت عوض کن.
- رنگ: متغیرهای `--accent` و `--bg` بالای بخش `<style>`.
- سرعت تایپ: مقدارهای `110` (نوشتن) و `55` (پاک کردن) در تابع `tick`.

## نکته

`server.js` همه آدرس‌ها را با کد وضعیت 503 همین صفحه را نشان می‌دهد تا موتورهای جستجو بفهمند توقف موقتی است.
