# استودیو بنر گیمینگ

سایتی برای ساخت پروفایل گیمینگ، بنر کانال، لوگو و کاور ویدیو. همه‌چیز داخل مرورگر ساخته می‌شود و هیچ تصویری به سرور فرستاده نمی‌شود.

## امکانات

- صفحه‌ی اصلی برای معرفی خدمات، نحوه‌ی کار، قالب‌ها، اندازه‌ها و سوالات پرتکرار
- ساخت پروفایل گیمینگ (۱۰۸۰×۱۰۸۰)
- طراحی بنر کانال در سه اندازه: یوتیوب (۲۵۶۰×۱۴۴۰)، کانال ۱۶:۹ (۱۲۸۰×۷۲۰) و هدر پهن (۱۵۰۰×۵۰۰)، با سه چیدمان
- طراحی لوگوی اختصاصی: پنج شکل نشان، هشت آیکون، سه چیدمان (عمودی، افقی، فقط نشان) و پس‌زمینه‌ی شفاف
- ساخت کاور ویدیو (تامبنیل): عنوان درشت با شکستن خودکار خط، برچسب قسمت، عکس اصلی در قاب، عکس پس‌زمینه با تنظیم تیرگی، در سه اندازه‌ی افقی (۱۲۸۰×۷۲۰)، عمودی (۱۰۸۰×۱۹۲۰) و مربع (۱۰۸۰×۱۰۸۰)
- حالت روز و شب با دکمه‌ی بالای صفحه (پیش‌فرض از تنظیم گوشی یا سیستم می‌آید و انتخابت یادآوری می‌شود)
- لوگوی واقعی: نشان و اسم فلزی سه‌بعدی با لبه‌ی برجسته، براقی، سایه و نور استودیویی، در چهار جنس (رنگ‌های طرح، کروم، طلایی، کربن). با گزینه‌ی «نشان و متن فلزی سه‌بعدی» خاموش می‌شود
- صفحه‌ی «تغییرات نسخه»، پیام معرفی آپدیت هنگام ورود (هر نسخه یک بار) و بخش «پیشنهاد امکانات» (آدرس مستقیم: `#changelog` و `#ideas`)
- منوی «توضیحات و آموزش» در بالای سایت (آدرس مستقیم: `#guide`) با توضیح کامل همه‌ی امکانات، آموزش قدم‌به‌قدم ساخت پروفایل، بنر، لوگو و کاور ویدیو، راهنمای اجرا و رفع مشکل
- شخصی‌سازی پس‌زمینه: درخشان، تک‌رنگ یا گرادیان (با رنگ دوم و زاویه)، و تزیین با آیکون‌های سه‌بعدی (عمق، تراکم، اندازه، شفافیت، رنگ، چیدمان جدید و مجموعه‌های آماده). روی لوگو، پروفایل و بنر کار می‌کند و دور اسم و نشان خالی می‌ماند
- هشت قالب آماده که با یک کلیک فونت، رنگ، الگو، قاب و آیکون را عوض می‌کنند
- انتخاب فونت از ۱۰ فونت (۳ فونت فارسی)
- انتخاب رنگ: شش تم آماده و چهار رنگ دلخواه
- افزودن اسم، آیدی و شعار کوتاه، و آپلود عکس آواتار
- شش الگوی پس‌زمینه، سه شکل قاب و افکت درخشش نئونی
- دانلود مستقیم تصویر نهایی با فرمت PNG، JPG یا WebP در اندازه‌ی کامل
- ظاهر مخصوص گوشی: پیش‌نمایش بالای صفحه می‌ماند و دکمه‌ی دانلود پایین صفحه ثابت است

## اجرا

نیاز: Node.js نسخه ۱۸ یا بالاتر. پکیج اضافه‌ای لازم نیست.

```bash
node server.js
```

بعد آدرس `http://localhost:3000` را در مرورگر باز کن. برای پورت دیگر:

```bash
PORT=8080 node server.js
```

در ویندوز (PowerShell):

```powershell
$env:PORT=8080; node server.js
```

## بدون سرور

فایل `public/index.html` را مستقیم در مرورگر هم می‌توانی باز کنی و همه‌چیز کار می‌کند. `server.js` فقط برای میزبانی روی سرور یا شبکه‌ی محلی است.

## ساختار پروژه

```
gaming-banner-studio/
├── server.js        سرور ساده + ذخیره‌ی پیشنهادها (بدون وابستگی)
├── package.json
├── README.md
└── public/
    └── index.html   خود سایت (HTML، CSS و JS در یک فایل)
```

## نکته‌ها

- فونت‌ها از Google Fonts بارگذاری می‌شوند، پس برای دیدن فونت‌ها و ساخت تصویر با آن‌ها اینترنت لازم است. بدون اینترنت از فونت‌های پیش‌فرض سیستم استفاده می‌شود.
- برای افزودن فونت تازه، آن را در لینک Google Fonts بالای `index.html` و در آرایه‌ی `FONTS` داخل اسکریپت اضافه کن.
- برای افزودن تم رنگی تازه، یک آیتم به آرایه‌ی `PRESETS` اضافه کن.


## پیشنهاد امکانات

پیشنهادهای کاربران با `POST /api/ideas` در فایل `data/ideas.jsonl` ذخیره می‌شود (هر خط یک پیشنهاد، حداکثر ۵ ارسال در دقیقه برای هر آی‌پی، سقف حجم فایل ۵ مگابایت).
برای دیدن آن‌ها از راه مرورگر، قبل از اجرا `IDEAS_ADMIN_KEY=رمز-دلخواه` را تنظیم کن و `/api/ideas?key=رمز-دلخواه` را باز کن. بدون این متغیر، آدرس خواندن همیشه خطای ۴۰۳ می‌دهد.
اگر پشت پراکسی (مثل Nginx) اجرا می‌کنی، `TRUST_PROXY=1` را بگذار تا آی‌پی واقعی کاربر برای محدودیت ارسال خوانده شود.
برای عوض کردن متن پیام آپدیت، آرایه‌ی `CHANGES` و `VERSION` را در `public/index.html` ویرایش کن.
